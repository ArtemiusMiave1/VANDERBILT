All asset included in this package are either created by me or free to use without crediting. This includes all the borders, boxes, portraits and Fonts in the Demo Asset Folder.
This is EXCLUDING DemoAsset 1 (the orange man prefab) which cannot be used for anything.

This tool allows the user to quickly add dialogue to their characters through CSV files the tool will make for you. CSV files are easily editable in third party software like Microsoft Excel allowing users to switch between the two programs for what they specifically want to do.
Portraits and portrait borders can easily be toggled on and off on a profile to profile basses. The Tool also helps user with quickly making their own custom UI, allowing every character to have their own unique dialogue layout or twenty characters using the same.
The code has been written to be easily modifiable to add more specific dialogue sets based on events, for instance a character will have new dialogue after returning from a quest or boss.

for setup and how to use please consult the Setup and Tool Guide PDF included in package.
